# 🚀 AI Resume Analyzer

An AI-powered Resume Analyzer that helps students, job seekers, and professionals improve their resumes for Applicant Tracking Systems (ATS). The application analyzes uploaded resumes, calculates an ATS compatibility score, identifies missing skills, and provides AI-generated suggestions to enhance resume quality and increase interview opportunities.

---

## 📖 Overview

The AI Resume Analyzer is a modern web application designed to evaluate resumes using AI-powered analysis and ATS scoring techniques. It enables users to upload resumes, receive detailed feedback, identify skill gaps, and improve their resumes based on industry standards.

This project demonstrates full-stack development using React, TypeScript, Vite, and Supabase with modern UI design and cloud-based backend services.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/VenkataAravind0080/AI-Resume-Analyzer.git
```

### Navigate to the Project Folder

```bash
cd AI-Resume-Analyzer
```

### Install Dependencies

```bash
npm install
```

---

## 🔐 Environment Variables

Create a `.env` file in the project root and add the following variables:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_PROJECT_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

> **Note:** Never commit your `.env` file to GitHub. It should remain private and is already excluded using `.gitignore`.
